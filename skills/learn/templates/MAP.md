# Learning map

One map for the whole project. Statuses are set by `/learn` from dated answers in the session files.
Edit freely; your edits win. `[proposed]` after the topic text marks a row drafted by the agent and
not yet accepted; in another cell it marks a proposed edit to that cell.

Status: not probed, gap, misconception, shaky, known, practised.
Prerequisites list topic IDs; a topic with none is a base topic. Child topics add a letter to the
parent ID (T03a). Sessions lists session file names, which name the mode; several are separated
by "; ", keeping the first and the latest two.
