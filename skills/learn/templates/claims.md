# Claims

One row per claim taught. Edit freely; your edits win.

- ID: C01, C02, and so on.
- Reason: why the claim matters, or why it was added.
- Basis: sourced, general (unsourced) or inferred; one basis per claim.
- Score: 0, 1 or 2, or "unchecked" for a pending claim (explained but not yet checked).
- Dates YYYY-MM-DD. The score history is in the session files.
- Interval: the spacing step. In the exam profile the due date is capped, not the interval.
- No "|" inside a cell; write it out ("given" for a conditional bar).
- A new claim starts with "-" for last practised and last score, the first spacing step as its
  interval, and next due = added + interval.
- Flag: blank, "source changed" or "sources disagree", set by `ingest`. Add the column if a file
  lacks it.
